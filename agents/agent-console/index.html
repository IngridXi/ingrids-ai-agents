Agent 治理巡检 只读盘点

盘点「有哪些 Agent、各干什么、边界是否清晰、有无重叠或空壳孤儿」。只读，去留由你决定。

情绪 / 偏好 Agent 越用越贴合你的偏好

侦测你对各 agent 的评价与情绪，学习「该多做 / 该避免」，沉淀成偏好规则：① 自动注入各 chat agent 的提示词指导后续操作；② 新偏好自动提交经验沉淀官（待审批，人工在环不变）。

检索复用 新问题先查历史经验

模拟「新问题进来时，先检索有没有适用过的方法论经验」（Voyager 技能库式）。输入规则或现象，看命中哪些已沉淀的经验。
