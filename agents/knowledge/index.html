Notion

连接、同步、以及把本地 latest 研究文件推送到 Notion。
🔑 连接
在 notion.so/my-integrations 创建集成，粘贴 Internal Integration Token（形如 ntn_ / secret_ 开头）。token 加密存本机钥匙串，不上传。
⚠️ token 有效 ≠ 能看到内容：保存后还要在 Notion 里给要读的页面/数据库授权这个集成（页面右上角 ··· → Connections → 勾选），否则搜不到。
⬆️ 研究同步官（本地 latest → Notion）
把电脑 latest 目录里的 .md / .docx 一键推成 Notion 子页面（docx 自动提取正文）。先点「刷新列表」，从下拉框选一个页面作为接收页，再点「立即推送」。

术语图谱

从 Zotero 文献自动提取术语，按共现关系连线，写入 Obsidian「术语库/」。
图谱里只想看术语、不想看到其他笔记时，在 Obsidian 图谱视图过滤框输入 path:术语库 即可。

权限自检

检测 macOS 受保护目录的可读性。研究助手「找不到文件」多半是这里没授权。
若某个目录标红：去「系统设置 → 隐私与安全性 → 完全磁盘访问」，点 + 添加 Electron.app，勾选后 ⌘Q 完全退出再重启。
