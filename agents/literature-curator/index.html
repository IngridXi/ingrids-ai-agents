文献管家

Literature Curator · Zotero 文献库无人值守入库与治理

运行概况

自动运行每 2 小时一次
Zotero 未开静默跳过，下次自动补做
API 消耗零（本地接口 + CrossRef）
脚本scripts/zotero/auto_ingest.py

它自动做什么

  • 1
    扫描新 PDF
    Downloads 新文件，state.json 幂等去重
  • 2
    导入 Zotero
    本地 API 导入，自动识别元数据
  • 3
    补元数据
    CrossRef 补年份作者（高置信才写）
  • 4
    自动分组
    按主题归入收藏夹，To Review 处理完即清
  • 5
    打标签
    标题关键词 → 受控主题标签
  • 6
    汇总报告
    当日摘要 + 每周周报

手动运行

点击「立即运行」触发一次文献入库与整理，输出会显示在这里。
也可以在终端手动跑：python3 ~/Dev/Ingrids-AI-Agents/scripts/zotero/auto_ingest.py
