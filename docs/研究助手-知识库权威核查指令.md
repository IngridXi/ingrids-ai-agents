## 四条铁律（违反任何一条都算失败）

1. **正确内容一律不许删除、不许重写。** 现有内容只要没错，一个字都不动。
2. **只有确认「确实错了」才可修改**，且必须用 `fs_edit` 做最小精确替换，**禁止整篇覆盖重写**。
3. **可润色**：在不改变原意、不删内容的前提下，把表述改得更精准、更专业、更符合学术规范。
4. **可补充**：发现缺失的权威规范、缺失的期刊、缺失的理论/方法，**追加**到对应位置，不覆盖原有内容。

## 权威来源优先级（只认这几类，其余不算「权威」）

1. 各刊**官方 Author Guidelines / Submission Guidelines**（以各刊官网为准，抓原文，不信二手转述）
2. 各刊**主编/编辑撰写的 editorial、使命声明、致作者信**
3. **方法学奠基文献**：Whetten (1989) 理论贡献、Sutton & Staw (1995) 何谓理论、Corley & Gioia (2011) 原创性×有用性、Colquitt & George (2011) 选题、Antonakis (2010) 内生性、Hinkin (1998) 量表开发、Eisenhardt (1989) 案例建构、Podsakoff (2003) 共同方法偏差等
4. **各理论奠基文献**：RBV、权变理论、代理理论、动态能力、悖论、交易成本、社会技术系统等
5. **报告指南**：PRISMA、STROBE、IMRAD 等

## 执行步骤（分阶段，每阶段结束自查）

- **阶段一 · 盘点**：`fs_list` + `fs_read` 通读知识库，列出一份「现有清单」——有哪些文件、各自覆盖了哪些权威点。
- **阶段二 · 联网比对**：按「期刊 × 维度（篇幅限制 / 结构要求 / 理论贡献 / 方法透明 / 数据政策 / 论文类型）」逐项 `web_search` + `web_fetch` 官方来源，与知识库里已有的数字、主张**一一对照**，标出「一致 / 冲突 / 缺失」。
- **阶段三 · 纠错与升级**：按四条铁律——错误改、缺失补、表述润色，正确的不动。
- **阶段四 · 复核输出**：逐条给出可审计的改动清单（格式见下）。

## 输出要求（必须给我一份可审计的清单）

对每一处改动，按此格式汇报：

```
- 文件：写作参考/JOM/01-底层逻辑与写作规范.md
- 类型：纠错 / 润色 / 补充
- 改动：改前「…」→ 改后「…」（或：新增「…」）
- 依据：<官方 URL 或文献出处>
```

**硬约束**：凡查不到官方来源的数字、页数、政策，一律标注「未查到」，**绝不凭记忆编造**。宁可少写一条，不可写错一条。
