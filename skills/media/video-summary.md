# 视频总结

把「一段视频」变成「不看也能掌握」的结构化中文总结。核心纪律：**字幕优先、无字幕才转写、只依据实际内容、绝不编造**。

## 第一步：获取内容（字幕优先，转写兜底）

1. **字幕优先**：优先抓取视频自带字幕 / 自动字幕（yt-dlp），最快、最准、保留时间戳。人工字幕 > 自动字幕；语言偏好 zh-Hans / zh / zh-Hant / yue / en / ja / ko。
2. **无字幕才转写**：没有可用字幕时，下载音频走本地 ASR（FunASR paraformer-zh / SenseVoice 多语言），复用会议纪要官的转写链路，内容不上云。
3. **多平台**：YouTube、Bilibili、抖音、小红书、小宇宙、微博视频等（yt-dlp 支持范围），以及本地音视频文件直接转写。
4. **多 P / 合集**：合集或分 P 视频逐段处理后再合并总结，明确标注「第 N P / 第 N 段」边界。
5. **长视频**：超长内容按章节切分处理，避免单次上下文截断丢失关键信息；切分处标注时间锚点。

## 第二步：结构化总结（带时间戳）

输出必须包含以下小节（Markdown，二级标题 `##`）：

- **## 视频主题**：一句话概括这个视频在讲什么。
- **## 核心观点**：分条列出，每条一句话抓主干，不啰嗦。
- **## 章节时间线**：按时间顺序列出关键节点，格式 `MM:SS 内容概述`，方便跳转回看。
- **## 金句/关键表述**：摘录原文里有价值的话，保留原意，标注大致时间。
- **## 事实与数据对照**：列出视频中出现的具体数字、日期、人名、出处；无法核实的标注「待核实」。
- **## 结论与启发**：总结结论，以及可迁移的启发或行动建议。
- **## 事实核查说明**：明确哪些内容依据字幕/转写直接可得、哪些需进一步核实。

## 第三步：基于内容的追问（问答）

总结完成后，用户可就视频内容继续追问（「他为什么这么说」「第 3 点依据是什么」）。追问只能依据已获取的字幕/转写回答；答不上的明确说「视频中未提及」，不靠常识补。

## 铁律

- **不编造**：不得虚构视频中未出现的数字、日期、人名、引语、结论。拿不准标「待核实」或「视频未提及」。
- **不越界**：转述不超过原文断言的强度，注意极性、因果、时间范围、比较对象。
- **区分来源**：明确标注内容是「来自字幕」还是「来自语音转写」，转写内容提示可能存在识别误差。
- **版权与合规**：仅用于个人学习与总结，抓取行为需遵守平台服务条款与当地法律；涉及他人内容时注明来源。
- **无内容不硬凑**：抓不到字幕、转写也失败时，如实说明失败原因，不生成空泛总结。

## 输出格式

先给「视频主题」与「核心观点」，再给「章节时间线」与「金句」，最后给「事实与数据对照」「结论与启发」「事实核查说明」。时间线保留可跳转的 MM:SS 锚点。
