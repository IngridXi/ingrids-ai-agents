# 个股深度研究

对单只股票做深度研究时，按九章框架走，每章给结论 + 证据，不堆砌、不臆造。覆盖 A 股（6 位代码）/ 港股（5 位）/ 美股（ticker）。

## 九章框架

1. **公司概况**：一句话说清它做什么、主营构成、上市地与代码、实控人/股权结构。
2. **商业模式**：怎么赚钱（收入来源、成本结构、关键客户/供应商）、毛利率背后的定价权。
3. **护城河**：品牌 / 网络效应 / 成本优势 / 转换成本 / 牌照资质，哪一条真的存在，还是伪护城河。
4. **成长性**：行业空间与渗透率、增长驱动、天花板、第二曲线。
5. **财务分析**：营收/净利（区分归母/扣非）、同比环比、毛利率、现金流、负债率、ROE，逐项看趋势与原因。
6. **估值**：三法交叉——相对（PE/PB/PEG 与自身历史 + 同行比）、DCF（简化，写明假设）、资产重置（重资产行业）。给出「当前贵不贵」的判断。
7. **风险**：行业 / 竞争 / 政策 / 财务 / 治理，分列并标重要度。
8. **催化剂**：未来 6–12 个月可能推动股价的事件（财报、新品、政策、订单）。
9. **结论**：多空平衡 + 估值区间 + 明确「这不是买卖建议」。

## 数据纪律

- 所有行情/财务/估值数字用 `web_search` 核实，标来源媒体 + 日期 + 是否实时；**禁止凭记忆报数**。
- 财报数字区分「归母净利润 vs 净利润」「同比 vs 环比」「财年 vs 自然年」。
- 估值假设（DCF 的 WACC、永续增长率）要显式写出，方便用户自己改参数复核。

## 输出规范

- 结构：先一句话结论摘要，再九章分点，最后风险 + 免责声明。
- 覆盖用户明确问的维度，没问的章节用一两个要点带过即可，不写流水账。
- 末尾附固定免责声明（见「金融分析」skill）。
