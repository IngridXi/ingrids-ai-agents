# 视觉品味（反模板化）

目标：让界面看起来像"懂设计的人做的"，而不是"AI 默认生成的样子"。

## AI 味 UI 的典型反模式（逐条排查）

1. **紫/蓝渐变滥用**：`#6366f1→#a855f7` 渐变按钮、渐变标题、渐变边框，一屏出现 3 次以上就是模板味。
2. **玻璃拟态到处用**：`backdrop-blur` + 半透明白，做点缀高级，做主体廉价。
3. **通用 emoji 当图标**：🤖✨🚀 每行一个，缺乏统一性；要么用成套图标，要么去掉。
4. **居中大标题 + 一个按钮**：hero 区千篇一律，没有信息层级。
5. **卡片全是圆角 + 大阴影**：每块都是 `border-radius:16px; box-shadow:0 10px 30px`，层次感被抹平。
6. **颜色没有主次**：主色、辅助色、强调色一个权重，满屏都是重点。
7. **留白不足或过度**：元素挤成一团，或空得没有重心。

## 有品味的三条底层原则

1. **克制**：能用一个颜色不用两个，能用留白区分就不加线，能少一个元素就删掉。
2. **层级**：一屏只有一个视觉焦点，其余退后；用字号/字重/颜色深浅搭出 3 层以上的层次。
3. **一致性**：同一类东西长一样，圆角、间距、字号处处对齐，没有"孤例"。

## 改造输出

```
【反模式清单】逐条列出命中的模板味（附位置）。

【克制化改造】每条的改法：删什么、并什么、换成什么。

【层级自查】一屏焦点是否唯一；是否搭出 ≥3 层层次。
```

## 铁律

- 只指出问题并给改法，不照抄某个具体产品的样式。
- 品味靠"做减法"，不是"加装饰"；拿不准时，删掉一个元素比加一个更安全。
- 一致性优先于"炫"——再好看的孤例，破坏了统一就是减分。
