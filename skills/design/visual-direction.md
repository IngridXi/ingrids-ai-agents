# 视觉方向（先定方向，再动手）

目标：避免"边做边想、做完风格割裂"。先花几分钟把方向定死，后续每个决定都回到这张卡。

## 定方向三问

| 问题 | 为什么 |
|---|---|
| ① 给谁用？ | 用户决定密度、字号、复杂度（内部工具 vs 大众产品完全不同） |
| ② 一句话气质？ | 只许一个词：专业 / 亲和 / 科技 / 高级 / 活力，别堆形容词 |
| ③ 有没有参考基准？ | 不照抄，但给 1–2 个"气质接近"的参照物定位调性 |

## 统一五件事（一个都别漏）

1. **字体**：中文 + 英文各一套，字号阶（标题/正文/辅助）定死，行高、字重、字距规则写下来。
2. **色彩**：主色 1 个 + 中性灰 8 档 + 语义色 4 个，60-30-10 用量（详见「配色方案设计」skill）。
3. **组件**：按钮、输入框、卡片、标签的圆角 / 描边 / 阴影 / 间距，一套规则，不许各写各的。
4. **动效**：过渡时长、缓动曲线、哪些地方能动、哪些地方禁止动（详见「动效与交互手感」skill）。
5. **页面语言**：空状态、加载态、报错态、成功反馈的文案语气，统一一个口吻。

## 输出格式

```
【视觉方向卡】
- 目标用户：…
- 一句话气质：…
- 参考基准：…（只作调性参照，不照抄）

【字体】中英文字体 / 字号阶 / 行高 / 字重。

【色彩】主色 / 中性灰 / 语义色 / 用量配额。

【组件规则】圆角 / 描边 / 阴影 / 间距统一值。

【动效】时长 / 缓动 / 动效范围。

【页面语言】空态 / 加载 / 报错 / 成功。
```

## 铁律

- 方向卡没写清之前不动手写 UI；做完每个模块回来对照，偏离了要么改方向卡要么改实现。
- 气质只许一个词；"又高级又活泼"等于没有方向。
- 参考基准是定位调性，不是抄它的色值和布局。
