# 布局与字体（排印）

目标：让界面"有秩序、可扫读"。排版是视觉品味的骨架，比配色更决定质感。

## 间距网格

- **统一用 4 的倍数**：4 / 8 / 12 / 16 / 24 / 32 / 48，别出现 7px、13px 这种零头。
- **同类间距一致**：卡片内边距、列表项间距、区块间距各归各档，不许同屏两种卡内边距。
- **用间距分组，少用线**：相关元素靠近（8–12），不相关的拉远（24–32），比加分割线更干净。

## 栅格与对齐

- **对齐是默认，错位是刻意**：文字左对齐基线对齐、元素边线对齐；任何不齐都要有理由。
- **栅格列数**：桌面 12 列，内容区用 8/8 或 6/6 拆分；别让卡片宽度忽大忽小。
- **留白是层级**：最重要信息周围留白最多；塞满 = 没有重点。

## 字号阶（中文界面）

| 用途 | 字号 | 行高 |
|---|---|---|
| 大标题 | 24–28 | 1.3 |
| 区块标题 | 18–20 | 1.35 |
| 正文 | 14–15 | 1.6 |
| 辅助/说明 | 12–13 | 1.5 |
| 标签/注脚 | 11–12 | 1.4 |

- **字重只分三档**：常规(400)、中等(500–600)、加粗(700)；一屏字重档位 ≤3。
- **字号差要够大**：标题和正文差 1.5 倍以上，否则没有层级，看着"糊"。
- **中文长文本行宽**：约 20–35 字/行，太长读着累，太短频繁换行。

## 字体选择

- **中文**：系统字体栈（PingFang SC / Microsoft YaHei）足够，正文别用艺术字。
- **英文/数字**：用同气质的一套（SF Pro / Inter），与中文混排时基线要顺。
- **数字用等宽或 tabular-nums**：金额、时间对齐时别跳来跳去。

## 输出格式

```
【间距规范】4/8 网格 + 各档间距用在哪。

【栅格】列数 / 拆分 / 对齐方式。

【字号阶】标题/正文/辅助/标签 + 行高 + 字重档位。

【字体】中文 / 英文 / 数字。
```

## 铁律

- 间距只用 4 的倍数，出现零头就是没按网格走。
- 一屏字重 ≤3 档、字号阶 ≥4 档，层级靠"差得够大"，不靠"都用粗"。
- 对齐是默认值；任何一处错位都要能说清为什么。
