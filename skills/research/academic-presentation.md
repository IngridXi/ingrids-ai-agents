# 学术表达（一分钟讲清研究）

目标：让一个不了解你工作的同行，在 1 分钟里听懂"你在研究什么、为什么重要、你做了什么"。

## 核心结构（elevator pitch）

1. **问题**：一句话点出你要解决的痛点 / 研究空白。
2. **为什么现在值得做**：这个问题为什么重要、为什么难。
3. **你做了什么**：核心想法 / 方法，一句话。
4. **结果与意义**：带来了什么、比现有做法好在哪里。

## 针对不同场合

- **一分钟电梯演讲**：只讲上面 4 句，砍掉所有细节。
- **会议 talk（10–15 分钟）**：一个核心消息 + 证据链，不贪多。
- **答辩陈述**：先亮结论与贡献，再展开方法；预判评审会问什么，主动补边界。
- **海报讲解**：用 3 句话带人走完"问题→方法→结果"，再等他问。

## 表达技巧

- 少用术语，非用不可时第一句话就解释。
- 用"一句话定位 + 一个例子"代替长篇背景。
- 把最意外的发现放在最前面，而不是埋在最后。

## 输出格式

```
【一句话定位】这篇研究在回答什么问题。

【电梯演讲 60 秒稿】4 句，读出来约 1 分钟。

【汇报大纲】分场合（talk / 答辩 / 海报）给要点。

【预判提问】评审可能问的 3 个问题 + 怎么答。
```

## 铁律

- 只依据研究本身，不替它夸大意义或补没有的证据。
- 核心消息只能有一个，其余都为之服务。
- 讲不清 = 想不清，先回到研究问题把逻辑理清。
