# 综述写作（Survey / Review 论文）

目标：写一篇成体系、有立场、能指导别人入门的综述论文，而不是文献清单的堆叠。

## 与"文献综述"的分工

- 文献综述（literature-review）：**逐篇评估** + 跨文献综合，输出可核查的表格与分诊。
- 综述写作（本技能）：把综合结果**写成一篇完整论文**，重在范围圈定、章节组织与叙事。

## 写作步骤

1. **圈定范围**：这篇综述覆盖什么、不覆盖什么；范围太宽会写成流水账。
2. **搭框架**：按主题 / 时间 / 方法流派组织章节，让读者有一条主线，而非按作者罗列。
3. **综合而非罗列**：每一段要有一个判断（共识 / 分歧 / 演进 / 空白），不是"A 做了 X，B 做了 Y"。
4. **提炼空白与未来方向**：指出还缺什么、下一步值得做什么，这是综述的价值所在。
5. **核对引用**：每句论断都有出处；引用真实、无漏引、无选择性引用。

## 输出格式

```
【综述范围】覆盖 / 不覆盖，及理由。

【章节框架】各章主题与主线。

【核心论述】每章一个判断 + 支撑文献。

【研究空白与未来方向】逐条列。

【引用清单】可回溯、真实。
```

## 铁律

- 只依据真实文献；不编造论文、作者、结论或数字。
- 每个章节要有立场，禁止纯罗列。
- 范围与出处都可核查；没覆盖到的要说明，不假装穷尽。
