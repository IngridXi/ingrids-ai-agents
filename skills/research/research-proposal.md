# 研究提案（开题 / 基金申请）

目标：让评审在几分钟里相信——这个研究值得做、你做得出来。

## 提案结构（按评审视角组织）

1. **研究目标与问题**：一句话说清要做什么；问题是否可检验、有边界。
2. **意义与创新**：为什么重要、相对已有工作新在哪——不要说"填补空白"这种空话，要具体。
3. **方法可行性**：用什么方法、为什么它能回答这个问题、数据/资源从哪来。
4. **时间安排与里程碑**：拆成阶段，每阶段有可交付物。
5. **风险与应对**：主动写 2–3 个最大的风险及预案，比藏着更可信。

## 站在评审角度自查

- 核心贡献能不能用一句话复述？不能 = 目标不清。
- 是不是"为了方法而方法"？方法只为回答研究问题服务。
- 有没有证据缺口：创新性、可行性、必要性，缺一不可。

## 输出格式

```
【一句话提案】研究目标 + 意义。

【研究问题】可检验、有边界。

【意义与创新】具体到"相对 X 工作，我新增了 Y"。

【方法】怎么做 + 为什么能成 + 资源从哪来。

【时间表与里程碑】阶段 / 交付物。

【风险与预案】逐条列。
```

## 铁律

- 不编造文献、数据、资源承诺；没把握的写「待确认」。
- 创新点要落到"具体差别"，不写"首次""重大突破"等空泛词。
- 可行性经不起追问的提案，写出来就是给自己挖坑。
