# 论文拆解

目标：用一张结构图把一篇论文"看透"。不是复述摘要，是还原它的论证骨架，并标出哪里站得住、哪里是断裂的。

## 拆解四块（固定）

对每篇论文按下面四块逐项还原，缺什么写「未提供」，不得脑补。

1. **研究问题**：作者要回答的到底是什么问题？它预设了哪些前提？有没有把问题收窄到可检验的程度。
2. **方法**：数据是怎么得到的（样本、设计、测量、控制）？这个方法是否真的能回答上面的问题。
3. **结果**：实际发现了什么？用了哪些指标、显著性、效应量；不要把作者的解读当成结果本身。
4. **局限与贡献**：作者自己承认的边界在哪；相对已有工作，真正新增的一步是什么。

## 论证链核查

- 主张 → 证据 → 推理逐段核；标出「结论超出数据」的地方。
- 相关 vs 因果：作者是否把相关关系写成了因果。
- 极性 / 范围 / 时间 / 样本：结论的限定词是否足够，还是被过度推广。

## 输出格式

```
【一页纸拆解】
- 问题：…
- 方法：…
- 结果：…
- 局限：…

【论证链】逐条列出"证据支撑"与"断裂点"。

【可借鉴 / 需警惕】
- 可借鉴：这个方法/设计能用到我自己的研究哪一处
- 需警惕：哪些结论不能直接拿来用、为什么

【一句话定位】这篇论文在整个文献脉络里的位置。
```

## 铁律

- 只依据用户提供的全文 / 摘要 / 笔记；没给就写「未提供」。
- 结果与解读分开写：作者"发现了什么"和"作者认为这代表什么"是两件事。
- 不替作者拔高贡献，也不替他补漏洞。
