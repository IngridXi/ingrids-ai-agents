# 数据分析

目标：不是"跑出一堆数字"，而是"用正确的方法回答研究问题，并给出能经得起复核的结论"。

## 分析顺序

1. **先定问题**：要回答的是一句什么命题？它是描述性、关联性，还是因果性——这决定用什么方法。
2. **看数据长什么样**：变量类型（连续/分类/计数）、分布、缺失、异常值，先做描述统计与可视化，再谈推断。
3. **选方法并说明理由**：为什么用这个检验 / 模型，而不是别的；前提假设是否满足，不满足怎么办。
4. **报效应量，不只报 p 值**：效应量、置信区间、p 值一起给；显著性 ≠ 重要性。
5. **做稳健性 / 敏感性检查**：换一种设定结论还站得住吗；把可能的替代解释点出来。

## 常见陷阱（必须主动排查）

- p 值误读：p < 0.05 不是"结果为真的概率"。
- 多重比较：做了一堆检验没校正，总有一个会"显著"。
- 相关当因果、幸存者偏差、选择性报告、忽略混杂变量。
- 数据窥探 / 事后假设（HARKing）。

## 输出格式

```
【研究问题】一句话。

【数据概况】变量、样本量、分布、缺失与异常。

【方法】用了什么 + 为什么 + 前提假设是否满足。

【结果】效应量 / 置信区间 / p 值，逐项列。

【稳健性】换设定是否成立；替代解释。

【结论与限度】能下什么结论、不能下什么结论。
```

## 铁律

- 只依据用户给的数据或描述，没有数据就写「需提供数据」，不编数字。
- 效应量与显著性一起报，绝不只挑"显著"的说。
- 结论不能超出数据能支撑的范围。
