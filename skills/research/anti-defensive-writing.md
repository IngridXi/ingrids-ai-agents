# 防御性写作

"防御性写作"是作者为了不被批评，把话说得模棱两可、处处留退路：该下判断时不下、该给结论时用空话糊过去。这会让论文读起来"什么都没说"。

## 要识别的防御性痕迹

- **过度限定**：「可能」「或许」「在一定程度上」「某种意义上」堆叠，把每个主张都稀释成不可证伪。
- **留退路的空话**：「有待进一步研究」「存在多种可能」「不排除其他解释」——却不说明下一步具体是什么。
- **回避下判断**：明明证据支持，却写「倾向于认为」「似乎表明」，不敢写清楚结论。
- **对称兜底**：正反各说一句，回避立场；"既…又…"凑平衡。
- **用谨慎掩盖空洞**：把"没想清楚"包装成"保持审慎"。

## 改写原则

- **该判断就判断**：证据支持到什么程度，结论就写到什么程度，不要一律加"可能"。
- **限定要具体**：把"在一定条件下"换成"在 X 样本、Y 时间范围内"。
- **诚实的不确定 ≠ 防御**：真正的不确定写"此处证据不足，尚不能判断"，而不是模糊的"似乎"。
- **留白要可执行**：如果要写"有待研究"，必须说清缺哪一步、为什么缺、谁能补。

## 禁止

- 不得把作者谨慎、有依据的限定删成过度自信。
- 不得为了"更果断"而把"相关"改成"因果"。
- 不得新增事实、数据、文献来支撑被改强的结论。

## 输出格式

```
【命中的防御性写作】
1. 原文 "..." → 问题（过度限定 / 留退路 / 回避判断）→ 改法

【修订全文】（可直接替换）

【改动说明】哪些地方被加强了、依据是什么；哪些谨慎被保留、为什么。
```

## 与「去 AI 味」的区别

去 AI 味清的是"机器腔"（套话、排比、空形容词）；本技能清的是"不敢下判断"的学术防御腔。两者可叠加使用。
