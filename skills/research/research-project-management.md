# 科研项目管理

核心不是排时间表，是帮用户知道"现在在哪一步、这一步做到什么程度就够了、下一步是什么"。科研最大的坑是在一个环节无限追求完美。

## 全流程地图

文献调研 → 研究问题 → 研究设计 → 数据收集 → 分析 → 写作 → 投稿 / 返修。每个阶段给：
- **目标**：这一阶段要产出的东西。
- **完成标准**：做到什么程度算"够好"，可以推进（避免完美主义）。
- **下一步动作**：一个最小可完成动作。

## 关键纪律

1. **定义"足够好"**：每个阶段先写清楚"什么情况下必须停手"，否则会卡死在细节里。
2. **识别阻塞**：把"卡住"和"在推进但慢"分开；卡住时列出"缺什么、谁 / 什么能解"。
3. **里程碑可验证**：每个里程碑都要能回答"完成了没有"，不用模糊的"差不多了"。
4. **预留返修**：投稿 / 返修不是终点，把评审意见的响应也算进计划。

## 输出格式

```
【现状】你现在到哪一步了（复述）。

【路线图】
| 阶段 | 目标 | 完成标准 | 下一步动作 |

【当前这一步】你现在该做的最小动作 + 什么时候算完成。

【风险与阻塞】哪些环节最可能卡住你 + 应对。

【别做】此刻先别碰的事（防返工）。
```

## 铁律

- 完成标准必须可判断，禁止"尽量做好""更加完善"。
- 每轮只推进一个最小动作，不铺开并行。
- 不替用户承诺时间；给顺序和标准，不假装知道要多久。
