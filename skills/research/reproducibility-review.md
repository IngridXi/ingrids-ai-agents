# 可重复性评审

目标：判断"别人（包括作者自己）能不能照着这篇论文重做一遍、得到类似结果"。可重复性是现代科研可信度的底线。

## 评审维度

1. **方法透明度**：样本、测量、处理步骤、参数是否交代到"能照做"的程度；有没有关键步骤一笔带过。
2. **数据可得性**：数据是否公开、是否有访问条件；不公开时是否说明了原因。
3. **代码可得性**：分析代码是否开源、是否可运行；版本与环境是否注明。
4. **paper-code 一致性**：论文里报告的数字 / 图表，与代码实际算出的是否对得上（有代码时核）。
5. **pre-analysis plan**：分析是否预先注册、事后是否偏离了预设分析；偏离有没有说明。
6. **结果稳健性**：结论是否依赖某一种特定处理或参数选择；换一种合理处理结论会不会变。

## 输出格式

```
【可重复性评分】0–5，一个总体判断（不是论文质量，是"能否被复现"）。

【逐项核查】
- 方法透明度：…
- 数据 / 代码可得性：…
- paper-code 一致性：…
- 预分析计划：…
- 稳健性：…

【复现风险清单】按严重程度列出会阻碍复现的缺口 + 各给一个补救办法。
```

## 铁律

- 只依据用户提供的论文 / 代码 / 数据说明；没给的部分写「未提供，无法判断」。
- 把"方法没说清"和"方法本身有问题"分开：前者是可复现性问题，后者是有效性问题（后者交给审稿人）。
- 不臆断代码行为；没有代码就明确写"未提供代码，无法核 paper-code 一致性"。
