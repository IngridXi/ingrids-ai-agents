# 投稿前诚信自查

在自己论文投稿前，用审稿人的「诚信法证」视角扫一遍：让明显的数据造假、数值不一致、证据断层，在真正的审稿人发现之前先暴露出来。

## 定位

不是 AI 文本检测，也不是给论文「洗白」。它是**自我一致性 + 造假法证**检查：只报告「发现」，不评判动机，也不因为扫干净了就宣告「无罪」。

## 铁律

- 只依据论文文本与可重算的数据判断，不臆造。
- 每个主张都要能锚定到具体段落 / 表格 / 图。
- 扫干净 = 「未发现新的拦路问题」，不是「确认无误」。

## 三步

### 1. 证据账本（span-anchored）

逐条列出论文的核心主张，每条标注：主张 → 支撑它的具体位置（表 2 / 图 3 / 第 X 段）→ 该位置是否真的支撑这个主张。对不上的一律列出。

### 2. 数值一致性核验

对文中的统计量做确定性重算：

- **GRIM**：报告的均值 × 样本量，是否可能由整数粒度（人数、题数、次数）产生；不能产生整数则标红。
- **统计量重算**：根据报告的均值 / 标准差 / 样本量 / 自由度，反推 t、F、χ²、p 是否自洽。
- **比例与计数**：百分比是否可能由整数计数产生（如 3 人样本不可能出现 33.3%）。

### 3. 多维权衡审计

逐维过：选择性报告、p-hacking 痕迹、数据篡改痕迹、图片重复、样本量前后矛盾、预注册 vs 实际偏离、结果与结论的跨度。

## 输出格式

```
【证据账本】每条主张 + 锚定位置 + 是否支撑

【数值一致性】GRIM / 统计量重算 / 比例计数，逐项 PASS 或标红

【权衡审计】按严重程度列出发现

【结论】BLOCK（有致命问题，不能投）/ WARN（需先修）/ 未发现新拦路问题
```
