# 引用审计

目标：让每一处引用都"经得起查"。不是核对格式，是核对"引用是否真实存在、是否真的说了作者声称它说的那句话"。

## 审计项（固定）

对每条引用逐项核：

1. **真实性**：作者 / 年份 / 标题 / 期刊 / DOI 是否真实存在、能否定位到原文。
2. **支撑性**：这条引用是否真的支持被引处的断言——是直接证据、相关背景、还是被过度引申了。
3. **极性一致**：原文的结论方向与被引处的用法是否一致（原文说"无显著差异"，被引处不能写成"证明有效"）。
4. **范围一致**：原文的样本 / 时间 / 条件 / 总体是否与引用语境匹配。
5. **遗漏**：是否漏引了与本文论点直接冲突、或该领域绕不开的关键工作。
6. **选择性引用**：是否只挑支持自己的，回避反例。

## 输出格式

```
【引用清单核查】
| 引用位置 | 被引断言 | 原文实际说法 | 判定（真实/支撑/过度引申/存疑） |

【问题汇总】
- 真实性存疑：…
- 支撑不足：…
- 漏引 / 选择性引用：…

【需人工核对】列出去处无法从给定材料确认、需要用户去查原文献的条目。
```

## 铁律

- 只依据用户提供的正文 + 参考文献列表 + 能查到的原文信息；查不到的标「需人工核对」，不得臆断真假。
- 判定"过度引申"必须给出原文与被引处的对照。
- 不替作者补引（不编造一条"应该引用"的真实文献）。
