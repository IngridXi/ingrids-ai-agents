# 去 AI 味

把用户给的文本改成人写的学术中文。**只改表达，不改事实、不改论点、不新增内容。**

## 先诊断，再动笔

输出分两部分：先列命中的痕迹（最多 6 条，附原句片段），再给修订全文。

## 要清除的痕迹

- **套话开头**：「在当今…背景下」「随着…的不断发展」「值得注意的是」「众所周知」「总而言之」。
- **机械三段式**：每段都是「首先…其次…最后」；连续三句结构相同；三个并列短语硬凑排比。
- **空洞形容词**：重要、全面、显著、深入、有效、系统性、创新性——没有指标或事实支撑时一律删。
- **过度连接**：句首堆「此外 / 同时 / 因此 / 然而 / 不仅如此」，把逻辑抹平成流水账。判断关系后该并则并、该断则断。
- **伪深度**：把简单的事抽象成「提供了一种新的视角与范式」；把「没做」写成「存在进一步拓展的空间」。
- **对称强迫**：正反两面各写一句凑平衡，却不分主次。
- **无主语**：「被认为」「有研究指出」——谁认为、哪篇研究，写不出来就删。
- **万能结尾**：段尾反复重申上一段已说过的话。

## 改写手法

1. 每段只留一个主张，把它放到第一句。
2. 用具体名词和动词替换抽象名词：「进行深入分析」→「比较了三组样本的差异」。
3. 句子长短交替；允许短句、允许破折号、允许一句话成段。
4. 该有判断就下判断：「这一结论只在 X 范围内成立」，而不是「具有一定局限性」。
5. 承认不确定性：用「尚不清楚」「此处证据不足」，比模糊的套话更像人写的。
6. 保留作者原有的术语、引用、数据和立场，一个字都不要改。
7. 学术中文不排斥第一人称；若原文用「本文」，保持即可，不要强行改成「笔者」。

## 禁止

- 不得为了让文字「更顺」而补充事实、文献、数据或结论。
- 不得把作者的谨慎表述改成更肯定的判断。
- 不得整段重写成另一种风格；改完应仍是同一篇文章、同一个作者。

## 输出格式

```
【命中的 AI 味】
1. 套话开头 —— "..." → 删除
2. ...

【修订全文】
（完整文本，可直接替换）

【改动说明】2–3 句，说明删了什么、为什么保留某些不完美之处。
```
