# 去 AI 味

把用户给的文本改成人写的学术中文。**只改表达，不改事实、不改论点、不新增内容。** 按下面七步顺序执行，不要跳步。

## 铁律（贯穿全程）

- 不得为「更顺」而补充事实、文献、数据或结论。
- 不得把作者的谨慎表述改成更肯定的判断。
- 不得整段重写成另一种风格；改完应仍是同一篇文章、同一个作者。
- 每改一处都要能说出「为什么改」。

## 第 1 步 · 通读定位

先完整读一遍，标出所有可疑处并分类记录，不动笔。改之前先判断：这篇文章的问题主要集中在哪几类（框架散 / 推理断 / 证据空 / 套话多）。

## 第 2 步 · 搭框架

- 每段是否只讲一个主张？主张是否放在第一句？
- 段落之间是「推进」还是「并列堆砌」？连续三段结构相同 = 机械排比，要打破。
- 有没有「首先…其次…最后」式的模板化推进？判断真实逻辑关系后该并则并、该断则断。

## 第 3 步 · 查推理

- 有无循环论证（把结论当前提再用）。
- 有无跳跃：主张 → 证据 → 推理是否闭合；相关不等于因果。
- 有无以偏概全、以权威代数据、以综述代证据。
- 「被认为」「有研究指出」——谁认为、哪篇研究，写不出来就删或改具体。

## 第 4 步 · 核文献与数字

- 每句话能否回到材料里找到依据？不能的一律标 [需补引] 或删。
- 数字、百分比、效应量是否可核查；没有出处支撑的精确数字要质疑。
- 引用是否真的支撑其主张（不要「某研究支持了 A」而原文其实讲的是 B）。

## 第 5 步 · 砍套话与防御性写作

删除以下痕迹：

- **套话开头**：「在当今…背景下」「随着…的不断发展」「值得注意的是」「众所周知」「总而言之」。
- **空洞形容词**：重要、全面、显著、深入、有效、系统性、创新性——无指标或事实支撑时一律删。
- **过度连接**：句首堆「此外 / 同时 / 因此 / 然而 / 不仅如此」，把逻辑抹平成流水账。
- **伪深度**：「提供了一种新的视角与范式」；「存在进一步拓展的空间」= 没做，要直说。
- **对称强迫**：正反两面各写一句凑平衡，却不分主次。
- **万能结尾**：段尾反复重申上面已说过的话。
- **防御性措辞**：「不能据此推断我具备稳定解决此类问题的能力」「本研究尚属初步」「可能存在一定局限」这类留退路的话——改成具体、有判断的表述（「这一结论只在 X 范围内成立」）。

## 第 6 步 · 语句逻辑 25 项

逐条扫，命中即改：句子过长（拆）、术语空泛（具体化）、无主语、指代不明、时态/单复数错、标点误用、重复用词、中英混杂、被动滥用、连续短句破碎、并列不平行、否定双重、逻辑词误用、范围词缺失（所有/多数/部分）、比较对象不清、时间锚点缺失、单位不一致、缩写未定义、名词堆叠、动词弱化（"进行/实施/开展"滥用）、比喻失当、情绪词混入、口语残留、过度绝对化、前后矛盾——共 25 项，逐项过。

## 第 7 步 · 输出

```
【命中的 AI 味】（最多 8 条，附原句片段 + 归类）
1. [套话开头] "..." → 删除
2. [防御性措辞] "..." → 改为 "..."

【修订全文】（完整文本，可直接替换）

【改动说明】2–3 句：删了什么、为什么保留某些不完美之处。
```

## 改写手法（改时参考）

1. 用具体名词和动词替换抽象名词：「进行深入分析」→「比较了三组样本的差异」。
2. 句子长短交替；允许短句、破折号、一句话成段。
3. 该下判断就下判断，用「这一结论只在 X 范围内成立」替代「具有一定局限性」。
4. 承认不确定性：用「尚不清楚」「此处证据不足」比模糊套话更像人写的。
5. 保留作者原有的术语、引用、数据和立场，一个字不改。
6. 学术中文不排斥第一人称；原文用「本文」就保持，不强行改「笔者」。
