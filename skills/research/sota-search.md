# SOTA 搜索（前沿追踪）

目标：在动手研究前，摸清一个方向"现在做到哪了、最好的是什么、我的想法新不新"。

## 检索策略

1. **圈定方向**：先用一句话定义要追踪的问题与关键词（含同义词、缩写）。
2. **多源交叉**：不只查一个库；对关键论文做引用追踪（谁引了它、它引了谁），找到源头与最新。
3. **找基准结果**：定位该任务常用的 benchmark / 数据集，以及当前最好（SOTA）的数字。
4. **判断新颖性**：你的想法是否已被做过——查关键词组合、看综述里的"未来方向"是否已有人填。

## 记录检索过程（可复现）

- 每个库 / 检索式 / 时间 / 命中数都记下，别人能照着复现。
- 对每条关键结果标：来源、年份、是否顶会顶刊、结论是什么。

## 输出格式

```
【检索问题】一句话。

【关键词与检索式】中英文 + 同义词。

【关键论文清单】按时间 / 相关度排：作者·年份·出处·做了什么·结果。

【当前 SOTA】该方向目前最好的方法 / 数字，及出处。

【新颖性判断】我的想法是否已被做过；还空着的是什么。

【检索记录】库 / 检索式 / 时间 / 命中数，可复现。
```

## 铁律

- 结论要能回溯到具体论文，不写"有研究表明"这种无出处断言。
- 检索不全就明说"仅覆盖了 X，可能有遗漏"，不假装穷尽。
- SOTA 数字必须给出处与时间，前沿变化很快，过期要标注。
