# 文献综述

分三步：**先多源检索，再逐篇分诊，最后跨篇综合**。沿用 ra 的 literature_triage 字段与「只依据给定材料」的纪律。

## 第零步：多源检索（可回溯）

- 先定检索式：核心概念 + 同义 / 上下位词 + 布尔组合；写清楚每个概念用了哪些词。
- **多源交叉**：不要只依赖单一数据库或单次检索；对关键文献做引用追踪（谁引了它、它引了谁）。
- **多数据库去重 + 验真**：跨数据库（arXiv、PubMed、Semantic Scholar、CrossRef、OpenAlex 等）检索后先去重，再验证 DOI / 出处是否有效。
- 记录检索过程：来源、检索式、时间、命中数，保证可复现。
- 检索命中不等于相关，进入第一步逐篇分诊。
- 若用户已提供文献清单，跳过本步，直接分诊。

## 第一步：单篇分诊

对每篇文献输出一条结构化记录。只依据用户提供的全文 / 摘要 / 笔记；没给的部分写「未提供」，不得从标题或常识推测。

```
文献：（作者 年份 标题；缺项写未提供）
relevance_score：0–100（对当前研究问题的有用程度，不是论文质量）
research_role：核心理论 | 方法参考 | 实证比较 | 背景 | 反例
key_contribution：一句话，用作者自己的说法，不替他拔高
theoretical_relevance：[]（能用哪个概念 / 框架 / 命题）
methodological_relevance：[]（可借鉴的设计、变量、测量）
empirical_relevance：[]（数据、样本、发现、边界条件）
useful_for：[]（具体能用在本研究哪一节 / 哪个论证）
limitations：[]（作者自述或文本可见）
cautions：[]（不能直接拿来用的原因）
```

评分说明：关键词命中不等于相关；高相关也可能只是背景文献。分数必须能由上面几栏解释。

## 第二步：跨篇综合

- 按**主题脉络**组织，不按「谁谁研究了什么」流水账排序。
- 明确写出：共识是什么、分歧在哪里、分歧来自方法差异还是样本差异还是定义差异。
- **研究空白**必须落到具体缺口（哪个关系没被检验 / 哪类样本缺失 / 哪个条件未覆盖），禁止「研究较少」这种说法。
- 把自己的研究问题放到脉络末端，说明它填补的是哪一条缺口。
- 矛盾证据单独列，不要被综合掉。

## 铁律

- 不编造文献、作者、年份、结论、页码。
- 转述不得超出原文断言的强度和范围；注意极性、因果、模态、总体、时间范围、比较对象。
- 引用某篇时给出可回溯的位置标记（章节 / 段落 / 用户提供的摘录），没有就标 `[需核对]`。
- 用户只给了摘要时，结论一律标注「基于摘要，未核对全文」。

## 输出格式

先给「分诊表」（每篇一行），再给「综合叙述」（按主题分节），最后给「空白与本研究定位」。若文献少于 3 篇，明确说明综合的局限。
